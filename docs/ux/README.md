# Organização operacional do KÔMA

O objetivo desta frente é reduzir ambiguidade e quantidade de decisões implícitas durante a operação do restaurante.

Princípios:

- uma ação financeira nunca deve presumir método de pagamento;
- seleção de itens, valor e método devem ser escolhas visíveis do operador;
- cada regra de negócio tem um owner canônico; UX não duplica autoridade do backend;
- atalhos só permanecem quando reduzem passos sem criar caminho paralelo;
- mobile e desktop devem compartilhar o mesmo modelo mental e os mesmos destinos;
- mudanças grandes são divididas por fluxo operacional, não por camada técnica;
- cada fatia precisa terminar com teste automatizado e merge verde antes da homologação manual.

O tracker vivo desta frente está em `docs/ux/tasklist-organizacao-uso.md`.
