# Kit de marca Kôma

Arquivos oficiais de uso geral da marca, com fundo transparente.

- `koma-logo-fundo-claro.*`: K escuro, para fundos brancos ou claros.
- `koma-logo-fundo-escuro.*`: K branco, para fundos pretos, verdes ou escuros.
- PNG: 1024 x 1024, indicado para sistemas que não aceitam SVG.
- SVG: versão vetorial, indicada para impressão, estandes e peças em grande formato.

Não adicione um retângulo de fundo aos arquivos. Escolha a variante conforme a cor da peça onde a marca será aplicada.
