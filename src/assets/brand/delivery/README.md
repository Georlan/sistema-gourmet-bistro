# Logos de origem dos pedidos

Arquivos PNG públicos obtidos de páginas oficiais em 25/10/2026, preservados sem redesenho, recorte, filtro ou recoloração. O componente apenas limita a caixa com `object-fit: contain`. Os logos identificam a origem de um pedido; não são um selo de integração homologada.

- iFood: página institucional https://institucional.ifood.com.br/ — variante branca publicada no próprio site.
- 99Food: repositório de marca https://restaurantes.99app.com/repositorio/ — logo exibido no material oficial para restaurantes, hospedado no CDN usado nessa página.
- Keeta (delivery Meituan): site brasileiro https://www.keeta-global.com/BR/pt-BR — imagem `NewKeetaLogo` declarada no metadado oficial de publisher. Não confundir com Keeta Network/cripto ou outras empresas homônimas.

`sources.json` registra URL exata, página de origem, dimensões, tamanho e SHA-256 de cada download. Total: 11.700 bytes. Os arquivos não são apresentados como criação do KÔMA ou licenciados como parte do código próprio; as marcas pertencem aos respectivos titulares.

Os imports são locais e entram no build/cache estático. Não há hotlink, requisição a plataformas por card nem dependência do CDN externo durante a operação. Novos parceiros sem asset verificado usam o ícone neutro e o rótulo do backend.
